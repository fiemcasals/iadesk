# 💡 Tips de Productividad

## 🎯 Técnicas Fundamentales

### 1. Pomodoro
- Trabaja 25 minutos sin distracciones
- Descansa 5 minutos
- Cada 4 ciclos, descansa 15-30 minutos

### 2. Priorización (Matriz de Eisenhower)
- **Urgente + Importante:** Haz primero
- **No Urgente + Importante:** Agenda
- **Urgente + No Importante:** Delega
- **No Urgente + No Importante:** Elimina

### 3. Bloqueo de Tiempo
- Asigna bloques específicos para cada tipo de tarea
- Evita contexto switching innecesario
- Agrupa actividades similares

## 📱 Herramientas Recomendadas
- **Todoist:** Gestión de tareas
- **Notion:** Organización personal
- **Slack:** Comunicación asíncrona
- **Calendar:** Bloqueo de tiempo

## ⚡ Hábitos Clave
- Empieza con la tarea más difícil
- Desactiva notificaciones durante trabajo profundo
- Toma notas de ideas distractoras para después
- Revisa objetivos diarios cada mañana
