# 🗂️ Índice del Módulo: `presentacion/`

> Módulo de presentación interactiva didáctica sobre la arquitectura técnica de IA Desk, Django, APIs y gestión de API Keys.

## 📋 Catálogo de Archivos de `presentacion/`

| Archivo | Temas y Palabras Clave | Resumen del Contenido | Cuándo Consultar |
| :--- | :--- | :--- | :--- |
| `INDEX.md` | `indice, catalogo, presentacion, diapositivas` | Catálogo local del módulo de presentación | Al buscar archivos de este módulo |
| `MEMORY.md` | `memoria, lineamientos, presentacion, didactica` | Memoria y lineamientos del módulo de presentación | Al consultar acuerdos de diseño de diapositivas |
| `presentacion.html` | `presentacion, slides, powerpoint, django, api, keys, arquitectura, tutorial, clase` | Presentación interactiva en HTML/CSS/JS con 10 diapositivas animadas explicando paso a paso la arquitectura Django, integración de Claude API y seguridad de Keys | Al exponer o repasar los conceptos fundamentales del sistema |

## 🏷️ Reglas del Módulo
- Este módulo reúne el material didáctico para explicar el sistema.
- Se navega con teclado (flechas `←` / `→`, `Espacio`, `F` para pantalla completa) o botones táctiles.
