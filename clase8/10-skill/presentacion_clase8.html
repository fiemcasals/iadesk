Conceptos Fundamentales

El Problema del Prompt Monolítico

Por qué los agentes complejos necesitan Skills desacopladas y autónomas

❌

Enfoque Monolítico (Ingenuo)

  • Un System Prompt de miles de líneas con todas las reglas de negocio.
  • Todos los archivos y catálogos cargados al contexto a la vez.
  • Degradación de atención: el modelo confunde reglas y pierde precisión.
  • Costos altos de API y lentitud en cada interacción.
✅

Enfoque Basado en Skills

  • Matcher: Detecta si el prompt activa la habilidad (ej: consulta de precios).
  • Executor: Ejecuta la herramienta especializada (SQL, Router, Memoria).
  • Aislamiento: Cada skill es testeable en Python de forma aislada.
  • Composición: El Agente orquesta las habilidades que necesita.

Flujo del Router

1. Llega prompt: "cuál es el cuaderno más barato".

2. El RouterJerarquicoSkill analiza el INDEX.md raíz y mapea cuaderno ➔ libreria/.

3. Abre bajo demanda libreria/INDEX.md descartando indumentaria y carnicería.

4. Se ahorra hasta un 80% de tokens en catálogos empresariales extensos.

Tool Calling & Persistencia

Consultas SQL y Cálculo de Óptimos

Cómo evitar alucinaciones numéricas delegando en motores relacionales

📐

1. Introspección (PRAGMA/DESCRIBE)

SQL ESQUEMA
-- La IA consulta el esquema de la tabla:
PRAGMA table_info(insumos);

/* Columnas reconocidas:
   id, nombre, descripcion, precio, stock, 
   categoria_id, palabras_relacionadas */
🎯

2. Sentencia SQL de Optimización

SQL OPTIMIZADO
-- Consulta para 'el cuaderno más barato':
SELECT * FROM insumos 
WHERE (LOWER(nombre) LIKE '%cuaderno%' 
   OR LOWER(palabras_relacionadas) LIKE '%cuaderno%')
ORDER BY precio ASC 
LIMIT 1;

-- Resultado exacto:
-- "Cuaderno económico tapa blanda" | $95 | Stock: 250
Psicología de la Venta & UX

Memoria Adaptativa, Mirroring y Permisos

Adaptación al vocabulario del usuario y respeto irrestricto a los acuerdos

🗣️

Mirroring Léxico

El agente hace una sumatoria de palabras del usuario: si habla informal responde con calidez ("¡Hola! Mirá, acá tenés..."); si habla formal responde protocolar ("Estimado, le informo...").

🔒

Persistencia de Permisos

Si el usuario otorgó permiso de cotización o reserva, la IA lo guarda en MEMORY.md. Regla de oro: Nunca volver a preguntar algo ya autorizado.

✨

"Respuesta Bonita"

Presenta el producto óptimo con estructura limpia: Título destacado, precio claro en ARS, stock garantizado y llamado a la acción comercial persuasivo.
